# CRM Lead Management System

## Overview

A full-stack CRM application to manage sales leads, track pipeline stages, and store notes.

## Tech Stack

* Frontend: React, Tailwind CSS
* Backend: Node.js, Express
* Database: SQLite
* Authentication: JWT

## Features

* User login authentication
* Lead CRUD (Create, Read, Update, Delete)
* Lead status tracking (pipeline)
* Notes system per lead
* Dashboard analytics
* Search functionality

## Setup Instructions

### Backend

cd server
npm install
npx nodemon server.js

### Frontend

cd client
npm install
npm start
